# e-Gov書類コンバータ

e-Gov（電子政府の総合窓口）等からダウンロードできるXML形式の公文書を、ブラウザ上でそのままHTML／PDFに変換・保存できるツールです。CSV形式の通知書類も見やすく整形して表示できます。

🔗 https://securecat.github.io/egov-doc-converter/

## 概要

- **XML + XSL → HTML／PDF変換**：e-Govが発行するXML公文書と、対応するXSLスタイルシートを組み合わせてHTMLに変換し、その場でプレビュー表示します。HTMLファイルとして保存したり、PDFとして保存したりできます
- **CSV → 見やすい表示に整形**：ヘッダー・明細・合計などに分かれたCSVをまとめて読み込み、カード形式や表形式に整形して表示します。Shift_JIS・UTF-8を自動判定します
- **ブラウザ内完結**：ファイルはすべてブラウザ内で処理され、外部に送信されることは一切ありません（サーバー側の処理はありません）

## 使い方

### XML + XSL → HTML／PDF

1. 「XML + XSL → HTML / PDF」タブを開きます
2. XMLファイルとXSLファイルを選択（またはドラッグ＆ドロップ）します
   - e-Govからダウンロードした**ZIPファイルをそのまま**渡してもOKです（中のXML・XSLだけを自動的に取り出します）
   - 複数の組み合わせをまとめて渡した場合、XML内の`xml-stylesheet`宣言から対応するXSLを自動で紐付けます
3. 「HTMLに変換して表示」を押すと、変換結果がその場でプレビューされます
4. 必要に応じて「HTMLとして保存」「PDFとして保存」で書き出せます

### CSV → 整形表示

1. 「CSV → 整形表示」タブを開きます
2. CSVファイルを選択します（複数ファイルに分かれている場合はまとめて選択可能）
3. 「見やすく整形する」を押すと、カードまたは表形式で整形表示されます
4. 「PDFとして保存」で書き出せます

## インストール

インストールは不要です。以下のいずれかの方法で利用できます。

- 上記のGitHub Pagesのリンクをブラウザで開く
- このリポジトリの `egov-doc-converter.html` をダウンロードし、ブラウザで直接開く

## 動作環境

`XSLTProcessor` に対応したモダンブラウザ（Chrome・Edge・Firefox・Safari等）が必要です。
