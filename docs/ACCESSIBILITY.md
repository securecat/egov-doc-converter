# アクセシビリティ

最終更新：2026-11-26

## 優先事項と目標

この文書が対象とするのは、次のとおりです。

- e-Gov書類コンバータのUI（ファイルの選択、変換・整形の操作、ステータスの表示、変換結果の保存）

UIは WCAG 2.2 のレベル AA を目標とし、これを上限ではなく下限と考えています。AAより厳しい独自の基準もあります（[貢献者への期待](#貢献者への期待)を参照）。

## 対応している環境

- ブラウザ：Chrome・Edge で動作を確認しています。Firefox・Safari は、まだ試していません
- OS：Windows 11 で動作を確認しています。macOS・iOS・Android は、まだ試していません
- スクリーンリーダー：NVDA で動作を確認しています。ナレーター・PC-Talker・VoiceOver などは、まだ試していません

## 既知の制限

- 「PDFとして保存」で作る PDF は、変換結果を画像にして貼り付けたものです。そのため、PDF の中の文字をスクリーンリーダーで読んだり、選択・検索したりできません。文字を含む PDF が必要な場合は、「HTMLとして保存」したファイルをブラウザで開き、ブラウザの印刷機能から PDF に保存してください
- XML を変換した結果の中身（見出しの構造、表の組み方、文字の大きさなど）は、行政機関が XML と一緒に提供している XSL ファイルによって決まります。このアプリでは、その構造を直すことはできません
- 変換結果のプレビューと CSV の整形結果は、PDF に保存したときの紙面と同じ見た目にするため、ダークテーマでも白い背景で表示します

## アクセシビリティの問題を報告する

問題は [GitHub Issues](https://github.com/securecat/egov-doc-converter/issues) で報告してください。日本語でも英語でも構いません。

次のことを書いてもらえると助かりますが、どれも任意です。

- 何をしようとしていたか
- 使っていた画面や機能
- 何が起きたか、どうなると思っていたか
- OS、ブラウザのバージョン、e-Gov書類コンバータ のバージョン
- 使っている支援技術（スクリーンリーダーなど）

障害の有無や内容を書く必要はありません。スクリーンショットや録画も必須ではありません。

## 対応の流れ

e-Gov書類コンバータ は個人で開発しているため、返信や修正の期限はお約束できません。それでも、できるかぎり早く対応します。

- 報告を確認したら、Issue で返信します
- 回避策があれば、お知らせします
- 修正をリリースする前に、問題が解消したかどうかの確認をお願いすることがあります
- 修正の内容は [CHANGELOG.md](https://github.com/securecat/egov-doc-converter/blob/main/CHANGELOG.md) に記載します

## 貢献者への期待

ここに挙げることは、人間の貢献者にもコーディングエージェントにも、同じように求めます。

UIを変更するときは、次を守ってください。

- フォームにはネイティブの要素（`<input>`・`<select>`・`<textarea>`）を使う。`<div>` や `<span>` をボタンの代わりにしない。画面内の操作には `<button>`、ページの移動には `<a>` を使う
- `disabled` 属性を使わない
- フォーカスインジケーターを消さない（`outline: none` を使わない）
- リンクの下線を消さない
- テキストのコントラスト比は、本文で 7:1 以上、補足的なテキストで 4.5:1 以上にする。ライトテーマとダークテーマのそれぞれで満たす
- 境界線やアイコンなど、テキスト以外の要素も、隣り合う色に対して 3:1 以上にする
- コントラストが必要な要素に `opacity` を使わない
- 文字サイズは、日本語で 16px 以上、英語で 14px 以上にする
- `font-family` は `sans-serif` にする（`system-ui` は使わない）
- ステータスメッセージを自動で消さない
- 自動スクロールなど、ひとりでに動くものを作らない

変更したあとは、キーボードだけですべて操作できること、スクリーンリーダーで内容が正しく読み上げられることを確認してください。

変換結果のプレビューと CSV の整形結果は、テーマにかかわらず白い背景で表示しています（[既知の制限](#既知の制限)を参照）。この部分の色を変えるときは、ダークテーマの色ではなく、白い背景に対してコントラスト比を満たしてください。
